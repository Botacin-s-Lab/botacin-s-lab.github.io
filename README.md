# botacin-s-lab.github.io

Website of Botacin's Lab, Texas A&M University: https://botacin-s-lab.github.io/

Built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/). Students update their own member card and project slot in [`cards/`](cards/README.md).

```bash
python3 -m venv .venv && .venv/bin/pip install -r docs/requirements.txt
.venv/bin/mkdocs serve
```
