## "ChatGPT" for Computer Security

<div class="feature-grid" markdown>

<div markdown>
### :material-cash: $150,000 grant
Started in 2025. Funds doctoral and Master's students in the lab.
</div>

<div markdown>
### :material-handshake: Scientific partner
Laboratory of Physical Science.
</div>

</div>

A security-focused large language model built to defend against malware. Attackers can use LLMs to write malware at scale, so the project builds a small LLM that writes detection rules at scale. It reads malware signatures, identifies malware and drafts rules that analysts review, so the analyst guides the machine and the machine does the heavy lifting. The model is meant to be small enough to run on a laptop, for example during incident response, and will be released publicly. Training uses a cluster of GPUs.

Read more in the Texas A&M Engineering article, [*"ChatGPT" for Computer Security*](https://engineering.tamu.edu/news/2025/02/chatgpt-for-computer-security.html) (Amanda Norvelle, March 11, 2025).
