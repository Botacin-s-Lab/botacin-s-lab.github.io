## How a project moves through the site

1. It starts as a slot on **Current projects**, filled in by the student who leads it.
2. When the paper, code and data are public, it gets its own page under **Published projects**, with links to the repositories, the dataset (for example on Zenodo) and the paper.
3. The slot on Current projects is then removed.
